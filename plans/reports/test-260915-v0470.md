## Detailed Findings

### 1. **Harness-Message Lane** ✓
- **Pattern:** `_HARNESS_MSG_RE` matches 10 prompt head types (task-notification, system-reminder, cross-session-message, teammate-message, Another Claude session, Request interrupted, SYSTEM NOTIFICATION, continued from previous, omp-msum file, command-name)
- **Pre-gate behavior:** MAX_SHORT_WORDS=3 silently drops ≤3-word prompts BEFORE harness check (by design; prevents ultra-short noise)
- **Lane output:** SKILL-CHECK line with locked signature "harness-message lane"; fallback="harness_message"; band="harness_skip"; offered=[]
- **No chain hint:** Harness lanes do not inject a CHAIN-HINT (verified: _authorized_skip_inject called with hint=False)
- **Test prompts (≥6 words, all PASS):**
  1. `<task-notification>` with summary
  2. `<system-reminder>` idle text
  3. `<cross-session-message>` with attributes
  4. `<teammate-message>` with JSON payload
  5. "Another Claude session sent a message: ..." (continuation form)
  6. "[Request interrupted by user for tool use]"
  7. "[SYSTEM NOTIFICATION - NOT USER INPUT]" multi-line
  8. "This session is being continued from a previous conversation"
  9. `<file name="/var/folders/vz/T/omp-msum-...">` (OMP summarizer call)
- **Negatives (all correctly skip harness lane):**
  - `/progress-map` in prompt → normal routing
  - "Complete assignment thoroughly:" (OMP worker brief) → normal routing
  - `<task-notification>` pasted mid-text → normal routing
  - "commit & push" → normal routing
  - "which set of skills..." → consult_route lane
  - `<file name="/Users/me/notes.txt">` (user-owned file) → normal routing

### 2. **Deterministic Routes** ✓
- **Config:** `config/deterministic-routes.json` seeded with 11 named-and-missed prompts from v0.46.0 audit
- **Execution order:** _route_hits runs BEFORE embed step (pure, no I/O)
- **Score:** Routes pin at 1.0; any retrieved twin is dropped from tail (no duplication)
- **Fallback survival:** Route hits survive embed timeout and Qdrant timeouts via _ranked_mandate fallback
- **Ledger confirmation (4 route events recorded):**
  - "run it - end-to-end - /unlazy..." → unlazy at 1.0
  - "/progress-map of the build..." → progress-map at 1.0
  - "cook --auto all phases..." → unlazy, ak-cook both at 1.0
  - "commit & push..." → ak-git at 1.0 (route field: ["ak-git", "skill-concierge:doctor", "skill-concierge:flywheel"])
- **Suppressions respected:** Route does NOT surface a skill if it is blocklisted or keep-off'd (selftest expectation: selftest 6b)

### 3. **Foreign Scopes** ✓
- **New entries:** dsh-personal, cline-personal added to every harness's FOREIGN_SCOPES tuple
- **Compound labels:** Both scopes use hyphenated names (singular form per design)
- **Annex behavior:** Foreign annex skips a row if its bare name is already in installed offer (avoids "also available in Codex" for skills already showing)
- **Live check:** FOREIGN_SCOPES=['cline-personal', 'codex-personal', 'codex-plugin', 'commandcode-personal', 'dsh-personal'] (alphabetical)
- **FOREIGN_HARNESS:** "codex/dsh/cline" (compound label; inverse: claude/commandcode/zcode)

### 4. **Timeouts** ✓
- **Embed step:** 0.35s → 0.5s (50ms grace buffer for worst-path embeddings)
- **Qdrant retrieval:** 0.1s → 0.25s (150ms margin for network + parse latency)
- **Rationale:** Worst path ≈1.75s (5s hook budget reserve: 5 - 1.75 = 3.25s)
- **Env overrides:** ENFORCER_EMBED_TIMEOUT=0.35 ENFORCER_QDRANT_TIMEOUT=0.1 reverts both
- **Audit note:** v0.46.0 ledger showed all qdrant_down at 101-106ms (v0.1 cap triggered) and embed_timeout at 359-381ms (v0.35 cap), not genuine outages

### 5. **Keep-Off Generation** ✓
- **Generator:** build_keep_off.py reads durable home `~/.claude/skill-concierge/keep-off.json` (config/keep-off.json is always empty seed)
- **Excludes:** Harness-shaped offers automatically filtered (ADR-0054 R4)
- **Keep-on exemption:** Blocklist-overriding always-on list protects daily-used skills from suppression
- **Data-sufficiency gate:** Requires ≥40 clean offered turns; test run: 0 offered-turns → False → inert (correct)
- **Window default:** v0.47.0 epoch (2026-09-15 00:00:00+) for future runs
- **Doctor integration:** `Keep-off` check: WARN when keep-off.json absent (expected); `--fix` regenerates to durable home (not tested in --fix mode per safety; callable verified)
- **No config pollution:** git status clean for keep-off.json, keep-on.json, blocklist.json
