## Root cause (code)

ADR-0052 scoped the per-session subtraction to Claude only ("other harnesses untouched", docs/adr/0052…md:50-51) — code matches the ADR exactly. Under OMP:

- `_plugin_gate_ok` returns True for every non-claude harness (`if not PLUGIN_GATE or RUNNING_HARNESS != "claude": return True`, hooks/scripts/enforcer.py:664).
- `plugin` and `omp-plugin` are NOT foreign under omp (:366-367) → offered on index membership alone.
- The OMP registry's per-entry `enabled:false` check (:581-583) fires only inside the twin test (foreign codex-plugin rows), never for offered rows. OMP's own runtime honors `enabled:false` (~/.bun/.../pi-coding-agent/src/discovery/helpers.ts:1186,1191-1192) — the offer claims invocability the harness would refuse.
- Discovery globs the OMP cache unfiltered (skills_discovery.py:805) — offer-time was supposed to be the gate; it isn't.
