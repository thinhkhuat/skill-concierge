## Cross-cutting

- **Two recommendations (R2, R7) propose new machinery to solve problems an existing, already-built mechanism solves at a smaller edit** — a curated route-config entry (R2) and a one-line scope-tuple fix (R7) — rather than reaching for the nearest existing layer first. Both existing layers (`_deterministic_hits`/`_ROUTES`, `_foreign_scopes`/`_invocable_twin`) were purpose-built for exactly this evidence shape and are directly reusable; the report's proposed new layers would sit next to them doing overlapping work, which is the over-engineering pattern this audit was asked to catch.
- **R8 shows a different failure mode: evidence possibly misattributed to a mechanism.** The report's own F9 narrative ("cross-harness annex") and its cited example rows (external-catalog-formatted) disagree. Recommending an env-var change before resolving which annex actually produced the evidence risks tuning the wrong knob — `ANNEX_MARGIN` (cross-harness) vs `ANNEX_COMPLEMENT`/`ANNEX_BEAT` (external, already hardened by ADR-0048 for this exact complaint).
- **Nothing in R1–R10 reads as "for future extensibility."** Every mechanism proposed (or correctly reused) maps 1:1 to a named finding's evidence; no speculative generality, no config surface wider than the cited cases need. R2's generic name-pin is the one exception, and it fails not on extensibility grounds but on duplicating an existing near-identical mechanism.
- **A senior engineer reading R1, R3, R4, R5, R6, R9, R10 as diffs would call them right-sized** — each is either a one-line/env change or a straight composition of tools that already exist. R2 and R7 would draw a "why didn't you just extend the thing that's already there" comment. R8 would draw a "which annex is this actually about" comment before any diff is written.

**Overall verdict:** the report's mechanism sizing is good on 8 of 10 recommendations; R2 and R7 propose duplicate machinery where a smaller edit to an existing layer already does the job, and R8's evidence needs re-attribution to the correct annex before a knob is touched.
