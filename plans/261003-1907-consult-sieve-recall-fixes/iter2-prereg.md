## Pass rules (all must hold)
- G1: n >= 25 for D_J20/D_J40, n >= 30 for D_SR40; at most 10% of primary cases missing.
- G2: recall gain >= 5 points. G3: losses <= 20% of gains (named in the output).
- G4: per-session one-sided sign test, Holm-adjusted p <= 0.05.
- G5: external rows median >= 4 and share rise <= 10 points.
- G6: Jev arms p90 latency <= 1500 ms absolute (Jev and sieve run in parallel; latency = max of the two); D_SR40 p90 <= baseline + 100 ms.
- More than one PASS: smallest Holm-adjusted p ships; tie → larger gain.

## What ships on a PASS
- D_J20 or D_J40: consult's `--fast` and full paths add Jev's top 10 for the task to the sieve candidates (script-side, where the TypeSafe key already lives: `scripts/consult_fit.py`), default ON behind a kill switch; list size per the passing arm.
- D_SR40: SKILL_CONSULT_SLOTS and SKILL_CONSULT_RRF default ON for consult_candidates and consult asks for top_n 40.
- Release with ADR, CHANGELOG, docs, version bump, installers. No PASS → nothing ships; the next iteration needs new data.
